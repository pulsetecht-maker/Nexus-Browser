## About

**Nexus Browser** is a modern desktop web browser built with Electron, designed to bring together everyday browsing, artificial intelligence, productivity, and customization in a single application.

Our goal is to create a browser that goes beyond traditional navigation, offering an intuitive interface and intelligent tools that make the web experience more useful and efficient.

Nexus Browser is being developed primarily for Windows, with a focus on performance, usability, and long-term evolution.

## Features

### Browsing Experience
- Multi-tab browsing.
- Navigation controls and address bar.
- Favorites management.
- Browsing history.
- Download management.
- Customizable home page.
- Modern desktop interface.

### Nexus AI

Nexus AI is the integrated artificial intelligence assistant designed to enhance the browsing experience.

Its capabilities include and aim to expand toward:

- AI-powered assistance.
- Contextual explanations.
- Web content summarization.
- Key information extraction.
- NVIDIA AI API integration.

### Privacy & Customization
- Custom browser interface.
- Privacy-focused tools.
- Domain blocking capabilities.
- Interface customization.

## Download & Installation

Nexus Browser is being developed with the goal of providing a simple installation experience for Windows users.

### Planned distribution formats

**Windows Installer (.exe)**

A traditional installer that will allow users to install Nexus Browser without manually configuring development tools.

Planned features:
- Simple installation wizard.
- Start Menu shortcut.
- Optional desktop shortcut.
- Uninstaller.
- Application icon and branding.

**Portable Version (.exe)**

A portable distribution option designed to run without a traditional installation process.

**Automatic Updates**

Future versions aim to include an automatic update system, allowing users to receive new releases more conveniently.

> These distribution options are development goals and are not necessarily available in the current version.

### Development Installation

For developers who want to run the project locally:

**Requirements**
- Node.js
- npm
- Git

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project:

```bash
cd nexus-browser
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm start
```

> Verify the actual startup script in package.json before using this command.
